# Inleiding
Reumatoïde artritis (RA) is een type chronische autoimmuun ziekte dat wordt gekenmerkt door ontstekingen in de gewrichten en progressieve weefselschade. RA komt ongeveer bij 0,5% - 1,0% bij de bevolking voor. Naast omgevingsfactoren spelen genetische regulatiemechanismen een belangrijke rol in het ontstaan en de progressie van RA. Verschillende studies tonen aan dat verschillende NK regulatory genes een belangrijke rol spelen bij RA.
